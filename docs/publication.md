# 发布副本说明

## 内容来源

本仓库由本地 `ERP_OPENCLAW` 项目整理而来。原工作区没有 Git 元数据；本次从源码与受控配置建立单独发布副本，保留业务代码，重写项目入口文档。

文档结构参考 [FinanceWiki Agent](https://github.com/harrycjs/financewiki-agent)，未复制其业务实现或凭据。ERP 的分析内容来自自身源码，不能把参考项目的 RAG、知识图谱或三层向量记忆当作本项目能力。

## 包含内容

- Python / Vue 业务源码、Agent / MCP / Web API。
- 现有测试与评测框架、前端锁文件。
- 无凭据环境变量示例、Docker 配置与空数据库 schema。
- 项目概述、技术架构、PRD、启动指南、计划与本次测试记录。

## 排除内容

真实 `.env` 与部署凭据、原始 `motorparts_db.sql` 数据导出、`src/local_sandbox` 用户内容、`src/download` 报告与附件、评测 traces / reports、临时测试目录、日志、虚拟环境、node_modules、构建产物及本地工具记录。

供应商报价 URL 映射替换为空 `mappings: []`。这意味着报价抓取需要自行配置；仓库不包含本地供应商端点和报价数据。

## 本次调整范围

核心业务源码逻辑保持不变；Git 按本机配置规范化文本换行。调整仅涉及文档、`.gitignore`、两个配置示例的说明 / 缺失字段、空报价映射。部分辅助文档保留较早的实现细节，遇到冲突以本次 [架构说明](architecture.md)、[角色说明](auth-rbac.md) 与实际源码为准。

发布不迁移数据库或运行状态。测试统计来自原工作区已有依赖环境；发布文件清单与内容校验只能证明快照一致性，不代表已在全新机器完成部署。
