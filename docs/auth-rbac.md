# 登录与角色权限使用说明

## 首次进入

1. 打开风驰网页（本地默认 http://127.0.0.1:3000/）。
2. 如果尚未创建账号，页面显示“创建管理员”；填写用户名、显示名称和密码。密码至少12个字符，不提供默认口令。
3. 管理员登录后，在“账户设置 → 账号管理”创建采购员、仓管员及审批人账号。
4. 至少创建一位其他审批人，用于审核管理员自己提交的申请。

首次初始化只允许成功一次；之后不提供公开注册。数据库迁移不创建或修改现有业务单据。

## 权限范围

- 采购员：采购申请、采购订单以及必要的供应商、库存查询。不能收货、调整库存或审批。
- 仓管员：库存查看、入库收货、出入库、盘点与库存流水。不能提交采购订单或审批。
- 审批人：全部业务功能与审批。不能审批本人创建的订单、采购申请或新增主数据申请。审批人和管理员编辑现有供应商、物料后立即生效，保存修改前后内容、操作人、原因和时间，不再由他人审批。
- 管理员：全部业务功能，以及创建账号、修改角色、停用账号和重置密码。同样禁止自审。

所有角色可使用智能助手，但工具调用遵循同一后端权限规则。人工确认工具执行仅允许提交业务，不代替正式审批。

## 身份与记录

操作人和审批人由服务器自动读取登录账号；网页或对话中填写其他姓名不能更换操作身份。新采购订单保存创建人账号ID，采购申请转订单保留申请人ID，库存与审批记录保存稳定账号标识。成功写操作另外记录身份、接口、时间与结果状态，不记录密码或会话令牌。

会话有效期8小时；退出登录、停用账号或修改密码将撤销对应会话。角色修改会在后续请求中重新校验。每个账号的聊天、长期记忆、临时报告及下载附件隔离保存。

历史手填操作人和匿名会话不能自动还原真实身份，因此不自动归属新账号。

## 部署

在项目目录执行 `python -m backend.migrate` 创建认证表，然后重启8080业务API、8001 MCP与8090网页API。Docker后端启动命令会自动执行迁移。生产前端需要重新构建。

默认允许localhost和127.0.0.1的3000、3001网页来源；其他域名通过 `AUTH_ALLOWED_ORIGINS` 设置逗号分隔的完整来源。启用HTTPS部署时设置 `AUTH_COOKIE_SECURE=true`，确保代理与页面使用一致协议。

Agent不再具备任意Shell或脚本执行能力；业务访问统一经过鉴权的MCP接口，本地图表工具仍可使用。
