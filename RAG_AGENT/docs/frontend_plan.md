# 本地业务工作台

用户要求继续补全完整应用；本阶段沿用已经确认的本地可验证范围。

采用 FastAPI 同源静态 HTML/CSS/JavaScript，不依赖 CDN 或前端构建服务。页面包括工作台、知识库/文档、问答、评测与设置。业务数据来自真实 PostgreSQL API；所有模型和文件内容以纯文本安全渲染。

实施顺序：
1. 新增文档列表、个人信息、本人会话历史、评测列表与明确的服务状态接口，并验证权限边界。
2. 实现中文导航、空状态、上传、任务状态/取消/重试、预览与下载、SSE 问答和历史、评测入口。
3. 提供本地启动与登录方式，更新 Docker 静态资源和运维说明。
4. 执行 API/数据库回归、静态语法检查、浏览器交互验收和代码审查。

验收范围：真实页面可以登录、创建知识库、上传文件、展示持久任务、查看会话/评测、取消任务。缺失外部服务时明确说明依赖，不产生模拟答案或伪造的成功状态。真实 MinerU/向量/图谱/模型效果与生产 SSO 不在当前本地验收结论中。
