# 可视化图表参数参考

## 本地支持的类型

- `bar`：横向条形图，用于类别对比。
- `column`：纵向柱状图，用于类别对比。
- `line`：折线图，按输入顺序连接各类别的数据点。
- `pie`：饼图，用于非负数值的占比展示。

这四种类型优先在本地生成 SVG，不依赖外部 MCP 服务。

## 调用参数

```json
{"chart_type":"bar","chart_config":{"title":"供应商等级分布","data":[{"category":"A级","value":7},{"category":"B级","value":9}]}}
```

- `data` 必填，包含 1–60 行；每行必须包含 `category` 和有限数值 `value`。
- `title` 可选。中文标签可直接使用。
- 饼图要求所有数值非负且总和大于零。
- 不支持分组、堆叠；请先按类别汇总，或分开绘制。
- 使用固定绿色配色和自动布局，不支持自定义宽高、主题、坐标轴标题或样式参数。
- 返回 `/api/artifacts/` 图片链接，使用工具返回的 Markdown 图片直接嵌入聊天正文。
- 图表是补充，不能代替用户要求的完整清单或具体答案。

## 可选外部扩展

其他类型仅在配置外部图表 MCP 且成功加载对应工具后可用。以运行时工具描述中的 `Available chart_type values` 为准，不预设数量或服务提供方。外部类型的参数遵循其实际工具 schema；不得将外部参数套用于本地图表。
